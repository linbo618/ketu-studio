# 课图快画

课图快画是一款面向课程作业、实验报告和答辩的轻量级矢量绘图工具。第一次打开会显示一个可编辑的单摆实验流程图。也可以从空白画布、四类学生场景模板或一段流程描述开始。

本项目对应「码力同行 · 实践挑战」原创赛道赛题 2。参赛材料见 [开发与验证记录](docs/development.md) 和 [项目演示视频](docs/demo.mp4)。

## 本地运行

需要 Node.js 20.19+（20.x）或 22.12+、npm 和支持 SVG、Canvas 与本地存储的现代浏览器。

```bash
npm ci
npm run dev
```

访问终端显示的本地地址，默认是 `http://localhost:5173/`。使用 Windows PowerShell 时，可以用 `npm.cmd` 执行相同命令。

```bash
npm run check
npm run build
npm run preview
```

构建产物位于 `dist/`，可由静态 HTTP 服务提供，支持部署在仓库子路径下。编辑、模板、按步骤生成和导出均在浏览器内运行。

## 使用方式

1. 在左侧选择「实验流程图」等模板，或点「新建画布」。
2. 选矩形、椭圆、菱形、文本、直线、箭头或画笔，在画布上点击或拖动。要让箭头随图形移动，先选箭头工具，再依次点击两个图形，也可以从一个图形拖向另一个图形。
3. 选择对象后拖动移动，拉右下角手柄缩放，拉上方圆点旋转。双击有文字的图形可编辑文字。右侧属性面板可以调整位置、尺寸、颜色、线型和字体。
4. 按住 Shift 点击或拖框选中多个对象，可以对齐、组合、复制和调整图层。用「视图」里的网格吸附和横向或纵向自动布局整理草稿。
5. 修改会自动保存到当前浏览器。在右上角项目菜单或导出窗口下载 `.ketu.json` 备份，之后用「打开项目文件」继续编辑。
6. 用「导出」下载 1× 或 2× PNG 或 SVG，选中「透明背景」可只保留图形。导出文件仅包含作品内容。

在「文字生成流程图」中可按行输入步骤，或用 `→` 分隔。首行可写 `标题：课程作业提交`。包含问号的步骤会生成判断菱形。生成结果是可编辑的新项目。

### 可选的 AI 生成

在「文字生成流程图」中选择「连接 AI 模型」，填入兼容 Chat Completions 的完整 URL、模型 ID 和服务所需的 API 密钥。普通部署使用 HTTPS，本机联调支持环回 HTTP。服务需要允许当前站点发起跨域请求。校验通过的模型输出会转成图形和连线，再进行自动布局。密钥保留在当前对话框内存中，请求仅发往用户配置的服务。

## 技术栈

| 技术 | 用途 |
| --- | --- |
| React 19、TypeScript、Vite | 界面、类型检查、静态构建 |
| SVG | 图形渲染、选框、连接点及矢量导出 |
| Canvas 2D | 在浏览器内将 SVG 光栅化为 PNG |
| Web Storage、JSON、File API | 自动保存、项目文件下载与导入 |
| Lucide | 操作图标 |

## AI 工具使用声明

- **工具名称**为 OpenAI Codex。
- **使用环节**包括选题讨论、功能设计、编辑器及图形模型初版实现、模板、导出、文档和浏览器验证。
- **人机协作**中，参与者根据校园已有软件和使用需求否定前两次选题，选定以课程、实验和答辩为场景的矢量示意图工具，并委托 Codex 实现。当前交付中的初版代码和自动化验证由 Codex 完成。参与者亲自完成的后续设计决策与源码修改，按实际 Git 提交和开发记录补充。
- **作品内 AI**可以通过外部模型生成流程图。默认的按步骤生成由本地规则解析与布局实现。
