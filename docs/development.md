# 开发与验证记录

## 源码结构

| 文件 | 职责 |
| --- | --- |
| `src/App.tsx` | 项目管理、撤销和重做、复制粘贴、快捷键 |
| `src/Canvas.tsx`、`src/Drawing.tsx` | 指针手势、画布交互和 SVG 渲染 |
| `src/model.ts` | 图形类型、连线几何、项目数据校验和本地存储 |
| `src/Inspector.tsx`、`src/Dialogs.tsx` | 属性与图层面板、模板、导出和生成界面 |
| `src/templates.ts`、`src/generate.ts` | 模板、文字解析、模型响应校验与自动布局 |
| `src/export.ts` | 项目文件下载、SVG 清理和 PNG 渲染 |
| `src/graphEdit.ts`、`src/symbols.ts`、`src/NodeGlyph.tsx` | 自动连线、避让插入、画布扩展和节点符号 |
| `src/Generator.tsx`、`tools/local-model/server.mjs` | 当前画布上下文、结构化生成阶段、模型连接和本机 Qwen 推理入口 |

## 数据和交互

项目文件以 `version: 1` 标记版本。图形有独立 ID 和统一的几何、样式字段。箭头可以保存源节点和目标节点的 ID，渲染时根据形状及旋转计算边界交点。画笔保存归一化轨迹，使笔迹可以缩放。拖动过程只更新预览，松开后将整次动作加入历史，便于一次撤销。项目文件导入时校验对象数量、图形类型、坐标、样式和连线引用。导出从当前 SVG 移除网格、选框、手柄和命中区域。

自动布局根据连线依赖分列或分行。遇到回路时按对象顺序选择起点。生成的图形沿用同一套编辑、保存和导出流程。流程较长、回路较多或节点尺寸接近页面上限时，可以在自动布局后手动调整。

## 验证路径

| 操作 | 预期结果 |
| --- | --- |
| 打开实验模板并拖动「器材准备」 | 进、出箭头跟随对象 |
| 修改文字、颜色和位置，再撤销和重做 | 变化与历史状态一致 |
| 新建项目并绘制基础图形、自由画笔和文本 | 图层面板显示新对象 |
| 复制、组合、缩放和旋转 | 撤销后回到修改前 |
| 保存、刷新、下载 JSON 并重新打开 | 标题、对象、样式和连线恢复 |
| 下载 SVG 与 2× PNG | SVG 无编辑辅助元素，默认画布的 2× PNG 为 1920 × 1280 |
| 按行输入课程步骤并生成 | 生成可继续修改和导出的独立项目 |
| 点击节点「＋」添加数据库，拖动连接点连接已有节点 | 自动放置数据库并连线，支持撤销和重做 |
| 在画布右边缘新增矩形 | 画布自动扩大，保存后尺寸可以恢复 |
| 输入「学生借书。第一步查找书籍，第二步前往柜台借书，第三步归还书籍。按步骤连线。」并调用本机 Qwen | 生成可编辑的节点和连线，预览后建立新项目 |
| 粘贴带分支标签的模型结构并接入现有节点 | 分支与原节点相连，接入动作一次撤销 |
