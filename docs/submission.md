# 活动提交信息

## 作品信息

- 项目名称：课图快画
- 参赛赛道：原创项目
- 选择赛题：赛题 2，轻量级矢量绘图 / 示意图工具
- 项目简介：面向课程作业、实验报告和答辩的示意图编辑器，支持学生场景模板、节点图形库、自动连线、箭头端点吸附、画布自动扩展、PNG/SVG 导出和本机 Qwen 辅助生成。

## 功能验收

- 基础图形、文本、自由画笔和对象操作可运行
- 箭头支持起点、终点、端点拖拽和节点吸附
- 节点支持四向扩展、自动连线和画布自动扩展
- 支持 12 个学生场景模板和 18 种图形
- 支持本地保存、项目文件导入、PNG/SVG 导出
- AI 生成会读取当前画布摘要，显示结构化生成阶段，默认应用到当前图
- `npm.cmd run dev` 会同时启动网页和本机 Qwen
